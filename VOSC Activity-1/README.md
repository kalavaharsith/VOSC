# Tic-Tac-Toe

A simple and interactive **Tic-Tac-Toe** game for two players.

## 🎮 How to Play

* The game is played between **two players: X and O**.
* **X goes first**, followed by O.
* Players take turns selecting an empty square on the 3×3 game board.
* The first player to get **three of their marks in a row** wins.
* A winning row can be:

  * Horizontally
  * Vertically
  * Diagonally
* If all nine squares are filled and neither player has three in a row, the game ends in a **draw**.
* Click **New Round** to clear the board and start another round.
* The **score is preserved** when starting a new round and is reset only when the page is refreshed.

## ✨ Features

* Two-player gameplay
* Interactive 3×3 board
* Win and draw detection
* Score tracking
* New Round functionality
* Simple and user-friendly interface
